# ☕ Java Básico — Curso em Vídeo

Repositório com códigos, exercícios e pequenos programas desenvolvidos durante meus estudos no curso de **Java Básico**, do **Curso em Vídeo**, ministrado por **Gustavo Guanabara**.

O repositório registra minha evolução nos primeiros contatos com a linguagem **Java**, passando pelos fundamentos da sintaxe até conceitos como estruturas condicionais, estruturas de repetição, funções, operadores e vetores.

## 🎯 Objetivo

O principal objetivo deste repositório é colocar em prática os fundamentos da linguagem Java através de exercícios progressivos.

Os programas foram desenvolvidos acompanhando os conteúdos apresentados no curso, permitindo praticar cada conceito individualmente antes de avançar para assuntos mais complexos.

## 📚 Conteúdos estudados

Entre os principais conteúdos praticados estão:

* Introdução à linguagem Java;
* Sintaxe básica;
* Variáveis;
* Tipos primitivos;
* Strings;
* Entrada e saída de dados;
* Operadores aritméticos;
* Operadores relacionais;
* Operadores lógicos;
* Operador ternário;
* Estruturas condicionais;
* Estruturas de repetição;
* Laços `while`;
* Laços `for`;
* Funções e métodos;
* Vetores;
* Busca em vetores;
* Manipulação de dados;
* Comparação de Strings;
* Uso de `JOptionPane`;
* Exercícios envolvendo situações do cotidiano.

## 🧪 Exercícios desenvolvidos

O repositório contém diversos exercícios utilizados para praticar os conceitos apresentados durante o curso.

### 👋 Primeiros programas

Os primeiros códigos trabalham conceitos básicos da linguagem, como:

* **Olá, Mundo!**
* Tipos primitivos;
* Teste de tipos;
* Números;
* Funções simples;
* Entrada e processamento de informações.

### ➕ Operadores

Foram desenvolvidos exercícios utilizando diferentes tipos de operadores:

* Operadores aritméticos;
* Operadores relacionais;
* Operadores lógicos;
* Operador ternário.

Esses exercícios ajudam a compreender como realizar cálculos e criar expressões utilizadas na tomada de decisões dentro dos programas.

### 🔀 Estruturas condicionais

Os exercícios também abordam situações em que o programa precisa tomar decisões de acordo com os dados fornecidos pelo usuário.

Entre os exemplos estão:

* Verificação de idade;
* Verificação de votação;
* Identificação de números pares e ímpares;
* Cálculo de médias;
* Quantidade de pernas;
* Classificação de situações.

### 🔁 Estruturas de repetição

O curso apresenta diferentes formas de repetir determinadas instruções.

No repositório estão presentes exemplos utilizando:

* `while`;
* `for`;
* Estruturas de repetição com condições;
* Contadores;
* Processamento de sequências.

Entre os exercícios estão programas como **Contador01**, **Repeticao01** e **RepetiçãoPara**.

### 📊 Vetores

Uma parte importante do repositório é dedicada ao estudo de **vetores**, permitindo trabalhar com conjuntos de valores armazenados em uma única estrutura.

Foram desenvolvidos exercícios envolvendo:

* Declaração de vetores;
* Preenchimento de vetores;
* Percorrimento de elementos;
* Busca de valores;
* Manipulação de dados vetoriais;
* Vetores contendo datas;
* Processamento de informações armazenadas.

Entre os exemplos estão:

* `Vetores01`;
* `Vetor03`;
* `Vetor05`;
* `VetorBusca`;
* `VetorDatas`.

## 🖥️ Interface com `JOptionPane`

Além da entrada de dados pelo terminal, alguns exercícios utilizam o **`JOptionPane`**, permitindo criar pequenas interfaces gráficas para interação com o usuário.

Um exemplo presente no repositório é o projeto:

```text
RepitaOptionPane
```

Esse tipo de exercício demonstra como o Java pode receber e apresentar informações através de janelas.

## 🚀 Como executar

### Pré-requisitos

* **JDK (Java Development Kit)** instalado;
* **NetBeans** ou outra IDE compatível com Java.

### Execução

1. Clone ou baixe o repositório.
2. Abra o projeto no NetBeans.
3. Escolha a pasta do exercício que deseja executar.
4. Compile o código.
5. Execute a classe que contém o método `main()`.
